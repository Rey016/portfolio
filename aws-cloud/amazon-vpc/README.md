Build a Virtual Private Cloud

Created an Amazon VPC to learn the fundamentals of AWS networking, including VPCs, subnets, and Internet Gateways.

Key Concepts

- VPCs
- IPv4 CIDR Blocks
- Subnets
- Internet Gateways
- AWS CLI

I also explored AWS CloudShell and compared using the AWS Console with the CLI.
