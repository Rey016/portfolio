Host a Website on Amazon S3

Hosted a static website using Amazon S3 by creating an S3 bucket, uploading website files, and configuring static website hosting.

AWS Services

- Amazon S3

Key Concepts

- S3 Buckets
- Static Website Hosting
- Access Control Lists (ACLs)
- Bucket Policies
- Bucket Endpoint URLs

The project also included configuring access permissions for website files and creating a bucket policy to prevent the deletion of the `index.html` file.
